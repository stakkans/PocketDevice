PocketDevice 2.1 — повний комплект
================================
1. Розпакуй архів у нову папку. Збережи резервну копію старої.
2. На GitHub відкрий stakkans/PocketDevice → Code → Add file → Upload files.
3. Перетягни ВСІ файли з розпакованої папки в корінь репозиторію, не сам ZIP і не папку.
4. Commit changes. Зачекай, доки GitHub Pages завершить публікацію.
5. На телефоні підключися до інтернету, відкрий PocketDevice, у «Налаштуваннях» натисни «Перевірити оновлення». Повернися в меню або натисни «Встановити оновлення», якщо з’явиться.
6. Переконайся, що в налаштуваннях написано PocketDevice 2.1 і «Офлайн: готово». Потім можеш перевірити авіарежим.
Не видаляй стару іконку застосунку та не очищай дані Safari: записки, імена, рекорди й налаштування залишаються в локальному сховищі цього самого застосунку.
Посилання: https://stakkans.github.io/PocketDevice/
У «Кореші»: Дії — особисті анімації; Речі — натисни або перетягни на персонажа.
Кімната — тап по меблях, світлу або радіо, режим перестановки і гості.
Пам’ять — зустрічі, дії, подарунки, теніс та поточний настрій.
Для перенесення персонажа затисни його приблизно на пів секунди й тягни; короткий рух — погладжування. Датчик руху потрібно окремо ввімкнути в кімнаті, якщо телефон підтримує.
Усі нові ресурси локальні. Інтернет потрібен для першого встановлення та оновлень; офлайн-доступ залежить від збереження кешу браузером.
