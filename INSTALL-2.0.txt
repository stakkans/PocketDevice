POCKETDEVICE 2.0 — повне безкоштовне оновлення
26.11.2026

ЯК ОНОВИТИ:
1. Розпакуй ZIP на комп'ютері в окрему папку.
2. Відкрий GitHub: stakkans/PocketDevice → Code → Add file → Upload files.
3. Перетягни ВСІ файли з розпакованої папки (не сам ZIP і не папку).
   Можна не завантажувати INSTALL-2.0.txt. Якщо GitHub питає — заміни однойменні файли.
4. Commit changes. Зачекай, поки GitHub Pages завершить публікацію.
5. На iPhone відкрий стару іконку PocketDevice З ІНТЕРНЕТОМ. Закрий і відкрий знову
   після оновлення. У Налаштуваннях перевір, що написано 2.0 та «Офлайн: готово».
6. Перевір режим польоту: карта, ігри, чтиво, персонажі. Не видаляй встановлений
   застосунок, якщо хочеш зберегти локальні дані.

НОВЕ:
• Статичний корпус, OLED прокручується окремо, стрілки без emoji.
• Дев'ять готових кольорів і власний колір; видимість плати, підсвітка.
• Шимпанзе (19 оригінальних PNG), козел, чортиця та Медуза, по 4 нові дії
  для нових персонажів. Імена, реакції, перетягування, приміщення, відвідування меню.
• Теніс, змійка, блоки, хрестики-нулики — кнопки й дотики.
• Карта Миргорода: 160 точок, нові фільтри, масштабування двома пальцями.
• Чтиво: 57 базових матеріалів, додаткові анекдоти, без книги про ДНР.
• Оригінальна мелодія запуску на першій взаємодії; музика в налаштуваннях
  (початково вимкнена), окремий рівень гучності.
• Офлайн кешує всі 46 основних файлів та зображень.

Старі ключі localStorage не змінено; при оновленні на тій самій адресі
записки, власні статті, імена, налаштування та рекорди тенісу зберігаються.
iOS може очищати локальне сховище в окремих ситуаціях, тому важливе
дублюй поза застосунком. Нові дані також не синхронізуються між пристроями.
Для першого кешування потрібен інтернет.
